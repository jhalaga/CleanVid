Private by design

By default, captions are read inside the YouTube tab and matched locally. If you enable OpenSubtitles, CleanVid sends the video title and your saved API key to OpenSubtitles to look for an alternate subtitle; the returned text is analyzed locally. No analytics or remote code is used.
